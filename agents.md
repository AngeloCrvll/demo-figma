## Commit Guidelines

Every commit must be a conventional commit. Please follow the guidelines below when comitting changes to this repository.

- Use present tense
- Use imperative mood in the subject line
- Limit the subject line to 50 charachter
- Capitalize the subject line
- Do not end the subject line with a period
- Use Feat: for new features
- use Fix: for bug fixes

## Security Guidelines
- never commit secrets or sensitive information to the repository
